🔑 Personal Finnhub API Key

The website owner can configure a common public Finnhub key in config.js so all visitors automatically access stock quotes, company search, profiles, metrics and headlines. The key is saved only in this browser's localStorage, not in GitHub. It is accessible to browser scripts and visible in network requests to Finnhub; use only on a trusted device.

A shared key in config.js takes priority over a personal key. WARNING: The shared key is visible to every visitor and in the public GitHub repository. Without a key, the limited public price feed is used. If you previously shared your key, rotate it before saving here.
